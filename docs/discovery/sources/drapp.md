# DrApp Odontología

- **URL**: https://www.drapp.com.ar/odontologia
- **Fecha de investigación**: 2026-11-22

## Problema que resuelve

Gestiona agenda, historia clínica, cobros, facturación y tareas asistidas por IA para consultorios y centros de salud, con soporte odontológico específico.

## Usuarios objetivo

Odontólogos independientes, consultorios con secretaría, clínicas y centros médicos multisede.

## Features detectadas

- Agenda e historia clínica electrónica
- Odontograma auditable y periodontograma
- Planes de tratamiento y presupuestos
- Cobros Mercado Pago y facturación ARCA
- WhatsApp, recordatorios y cobro anticipado
- Teleconsultas, recetas y órdenes
- Roles, API pública, exportación e IA clínica

## Pricing

Planes desde ARS 33.999 por agenda al mes más IVA. Prueba Premium de 15 días.

## Posicionamiento

Ecosistema modular de gestión sanitaria que puede crecer desde un consultorio hasta centros con múltiples profesionales.

## Diferenciadores

API pública, módulos activables, IA para notas clínicas y soporte de varias especialidades además de odontología.

## Notas del investigador

No es exclusivamente odontológico. La prevención de solapamientos por sillón o box no fue evidenciada públicamente.
