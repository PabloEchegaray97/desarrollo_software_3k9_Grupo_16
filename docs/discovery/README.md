# Discovery - sistema de turnos odontológicos

Estado: **checkpoint y verificación humana de cinco fuentes completados el 2026-11-22**.

## Artefactos

- `informe-discovery.md`: informe principal conforme a las secciones A-D de la consigna.
- `informe-discovery.pdf`: versión entregable generada desde el informe.
- `matriz-evaluacion.csv`: matriz editable con puntajes, pesos y totales.
- `discovery.md`: resultado estructurado del checklist de once puntos.
- `sources/`: quince notas normalizadas, una por solución investigada.

## Trazabilidad

| Requisito de la consigna | Evidencia |
|---|---|
| Al menos 15 sistemas | `sources/` e informe, sección A |
| Matriz ponderada 0-5 | `matriz-evaluacion.csv` e informe, sección B |
| Estándares, diferenciales, vacíos y oportunidades | Informe, sección C |
| Cinco demos, tres referencias UX y MVP | Informe, sección D |
| Checklist de once puntos | `discovery.md` |
| Verificación personal de cinco fuentes | Informe, sección Verificación; estado completado |
